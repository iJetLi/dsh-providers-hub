# Jet Hub

登录并管理多家 AI 编程服务的账号，把它们的模型接进 DSH 的模型选择器。

一个插件管住**账号、凭据、模型列表、积分**这四件事，全部在设置页完成，不注册任何斜杠命令。

## 它能做什么

- **多账号池** —— 同一个服务可以登录多个账号，按可用性自动选号；**支持请求级换号的渠道**会在某个账号临时不可用（限流 / 冷却 / 余额耗尽）时自动换下一个，不需要你手动切换。
- **凭据静默续期** —— **有刷新端点的渠道**在凭据到期前自动续期，不必再打开浏览器重登。少数渠道没有刷新端点（由登录方式决定，例如用浏览器 Cookie 或扫码登录的那些），到期后需要重新登录一次，插件会把这条写进错误文案，而不是让请求静默超时。
- **模型列表开关** —— 逐模型（或逐渠道）决定哪些出现在模型选择器里。
- **积分与每日签到** —— 为**支持积分查询的渠道**提供统一面板（少数渠道没有可查的积分，就不显示）；支持签到的渠道可以一键领取当日额度，**自动签到默认开启**，可以在设置里关掉。
- **本机 OpenAI 兼容网关** —— 供其它客户端复用已登录的账号（默认只监听回环地址；设置里的「允许局域网访问」会把它开到非回环地址，请注意网络环境）。

## 怎么开始

1. 在**主导航 → Jet Hub**（插件启用后侧栏会多这一行）打开面板；若这一行被隐藏了，也可以从插件详情页的设置卡片把「面板入口」设为设置页。
2. 点「新建账号」，选择渠道，按提示完成登录（扫码、浏览器授权或粘贴回调链接，各家不同）。
3. 回到模型选择器，选中该渠道的模型即可开始对话。

## 安全边界

- **凭据只存在本机** —— 凭据交给 DSH 宿主的凭据存储保管（本机落地为 `~/.dsh/.credentials.yaml`），插件不上传、不外发。
- **插件自身的请求直连官方端点** —— 你与上游之间没有第三方中转。唯一例外是**你自己开启**的本机网关：它把本机客户端的请求转发给你已登录的账号。
- **不做配额或计费欺骗** —— 不伪造积分、不代刷额度、不绕过账号级限制（限流、冷却、订单校验都如实遵守）。遇到拒绝，它报出原因而不是假装成功。

## 它不是什么

- **不是模型服务** —— 它不提供算力，只管理你已有的账号。
- **不替你接受条款** —— 使用前请自行确认各服务提供方的服务条款。
